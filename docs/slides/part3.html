8 · CLAUDE.md (AGENTS.md)

Two kinds of instruction

With no instructions of your own, a model answers everyone’s question the same way. Instructions are how that gets changed.

The provider’s

The system prompt ships with the product and is sent on every turn. It regulates behavior: what the assistant is, what it declines, how an answer is formatted.

You do not edit it.

Yours

Added on top. It customizes behavior: how you want work done, what your files hold, the conventions you follow.

You choose what it says and where it applies.

What reaches the model before your prompt

Part Who sets it When it is sent
System prompt the provider every turn
Tool definitions the product, and what you connect every turn
CLAUDE.md you every turn
A skill’s description you every turn, one line each
A skill’s body you only when the description matches

Anything sent on every turn costs money and latency, and takes up the model’s attention.

What is in a system prompt

Identity what it is, who made it, what today’s date is
Format when to use markdown, how long an answer should run, when to use a list
Tools when to search the web, when to write code, when to make an artifact
Refusals what it declines, and how
Character what to do when it is uncertain, how much to hedge

Anthropic publishes the ones in the Claude apps, dated and by model: platform.claude.com/docs/en/release-notes/system-prompts

CLAUDE.md, by scope

Claude Code reads every CLAUDE.md from the top of the filesystem down to the folder you started in, and puts them all in context:

File Applies to
$HOME/.claude/CLAUDE.md every folder you work in nobody
path/folder/CLAUDE.md work in that folder the team, if you commit it

The closest file is read last. Keep each one under about 200 lines — all of them are in the context window before you type.

  • OpenAI and Google call it AGENTS.me
  • Desktop apps have analogous “instructions” settings

A digression on file systems

Windows File Explorer hides the actual filesystem locations of common folders. You can do the following to see where your home folder is.

  • Windows: Start -> Command Prompt. Then type cd $HOME and Enter and then pwd and Enter. That is your home directory.

  • Mac: Enter the same commands into the Terminal app.

  • lab803: Terminal in left pane. Enter the same commands.

What belongs in a CLAUDE.md

Yes

  • How you want numbers handled
  • What the folders hold
  • Conventions everything here follows
  • Anything you have corrected twice

No

  • Steps for one particular task
  • Anything longer than a page
  • Background that can be looked up
  • A tool you use once a month

In Claude Code, # at the start of a message appends a line to one of these files, and /memory opens them for editing.

  • Then log out (top right corner), log back in, and ask anything.
  • Then ask it to delete the “always answer like a pirate” from the CLAUDE.md, log out again, and log back in.

9 · How it remembers you

Memory

  1. While you talk, it saves individual topics — not a transcript, and not a summary written when the conversation ends.
  2. Those topics arrive with the system prompt, ahead of your first message.
  3. Nothing is searched and no tool runs. There is no sign of it in the conversation.
  4. Each project has its own memory. Topics from one do not reach another.

Pushed, or pulled

Memory

Saved as you go and placed in the conversation without your asking. Whether it applies is decided before you type.

Chat search

You ask for it. It searches your past conversations, you see the tool run, and the answer cites the chat each piece came from.

Settings → Memory lists the topics. Read, edit or delete any of them, pause it, or reset it. Say what to remember or forget in the chat and it applies to your next conversation. An incognito chat forms no memory.

10 · SKILL.md

A skill is a folder

skill-name/
  SKILL.md          the instructions
  references/       longer material, read only when needed
  scripts/          code the skill runs rather than regenerates

SKILL.md opens with two lines of metadata (name and description) and then plain text.

In Claude Desktop: Choose Customize in left pane. Then Skills. Explore or Add.

The same file in other agents

Anthropic wrote the format and released it as an open standard. The others adopted it rather than inventing their own.

Agent Where it looks
Claude Code .claude/skills/
Codex and ChatGPT .agents/skills/
Gemini CLI .gemini/skills/, or .agents/skills/

Same file, same description-first loading. Put the folder in .agents/skills/ and both Codex and Gemini CLI find it.

Creating a skill

  • Work with AI until you get what you want
  • Tell AI to create a skill so you can get the same thing the next time
  • Give the skill a meaningful name.
  • As you use it and find things to add or modify, tell AI to edit the skill.

Three ways to invoke

Slash command /skill-name
By name “use the … skill”
Automatically “build …”

The third only works when the skill description clearly applies.

Gmail MCP server — tools it exposes

  • search_threads — find threads matching a query
  • create_draft — start a reply, unsent
  • get_message — fetch one message
  • update_draft — edit a draft
  • list_labels — list the labels on the account
  • label_message — add or remove a label

↕

Gmail — what the API exposes

  • GET users/me/threads?q= — search
  • POST users/me/drafts — create draft
  • GET users/me/messages/{id} — read
  • PUT users/me/drafts/{id} — update draft
  • GET users/me/labels — list labels
  • POST users/me/messages/{id}/modify — labels and state

The harness gets the tool descriptions from the server.

It sends that list to the LLM with every request.

The LLM answers with a tool name and arguments. The server turns that into an API call.

Tools from MCP servers

Tools written by somebody else, running on a server somebody else operates. Thousands of MCP servers exist already.

What you add

A URL, in the agent’s configuration

What arrives

A name, a description and an input schema for every tool the server publishes

What stays there

The code, and the credential it uses to reach the service

To the model these are more entries in the same tool list. What differs is whose machine runs them.

Example: Google’s Gmail server

search_threads     get_thread        get_message
create_draft       list_drafts       list_labels
label_thread       unlabel_thread
label_message      unlabel_message

Ten tools, at https://gmailmcp.googleapis.com/mcp/v1. Published at developers.google.com/workspace/gmail/api/reference/mcp.

Example: Anthropic’s Gmail server

12 · Plugins

What you install

A plugin is a folder somebody else published. Installing it adds their work to your Claude in one step.

What it can carry

Skills, slash commands, subagents, hooks, and MCP servers.

What you get

Every file and script in it, without being told which ones to copy where.

Anthropic’s plugin marketplace

https://code.claude.com/docs/en/discover-plugins

Try it

Give Claude the following prompts

/plugin marketplace add kerryback/skills
/plugin install finance-data@kerryback

Then ask Claude what was installed. Finally, ask Claude to compute monthly stock returns for Apple since the start of 2020 and to produce a histogram.

You should see Claude say “using the finance-data skill”
